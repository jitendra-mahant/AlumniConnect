# AlumniConnect

**College Alumni Association & Professional Networking Platform**

AlumniConnect is a web-based platform designed to connect college students with verified alumni. It provides a centralized environment for professional networking, mentorship, job and internship discovery, referrals, communication, and career guidance.

## Project Overview

Students often find it difficult to communicate with alumni and obtain reliable guidance regarding careers, internships, placements, higher studies, and industry opportunities.

AlumniConnect solves this problem by creating a dedicated college alumni network where students and alumni can interact professionally.

## Key Features

- Student and Alumni Profiles
- Alumni Search and Filtering
- Professional Networking
- Connection Requests
- Jobs and Internship Opportunities
- Alumni Referral Requests
- Mentor Discovery
- Mentorship Requests
- Messaging System
- Notifications and Alerts
- Job Match Ranking
- Data Structure Demonstration
- Responsive Dashboard

## Data Structures Used

| Data Structure | Application |
|---|---|
| Graph | Alumni connection network |
| BFS | Finding shortest degree of connection |
| Hash Map | Fast user and skill lookup |
| Set | Unique skills and mutual connections |
| Queue | Messages and notifications |
| Priority Queue / Heap | Job and notification ranking |
| Trie | Prefix-based people and skill search |

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/jitendra-mahant/AlumniConnect.git
```

### 2. Open the project

```bash
cd AlumniConnect
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

Open the localhost URL displayed by Vite in your browser.

### 5. Create production build

```bash
npm run build
```
